# Assincronias Ventilatórias – Ferramenta Educacional

Aplicativo educacional para **leitura estruturada de assincronias paciente–ventilador** a partir de **curvas ventilatórias** (pressão, fluxo e volume).

O sistema **organiza sinais, padrões e interpretações possíveis**, com base em literatura científica consolidada, **sem orientar conduta clínica**.

---

## Finalidade e escopo

Este aplicativo foi desenvolvido como **ferramenta educacional** para apoiar o raciocínio na leitura de curvas ventilatórias em contextos de ensino, treinamento e discussão clínica.

- Não prescreve ações  
- Não orienta ajustes ventilatórios  
- Não substitui julgamento clínico, avaliação individual ou protocolos institucionais  

O app **torna explícita uma estrutura de leitura**, não gera decisões.

## Base científica

O aplicativo se baseia em conceitos descritos na literatura sobre:
- Assincronias paciente–ventilador  
- Interação paciente–ventilador  
- Análise de curvas ventilatórias  
- Mecânica respiratória em ventilação mecânica  

Esses conceitos foram **organizados em um framework educacional**, descrito no manuscrito associado.
